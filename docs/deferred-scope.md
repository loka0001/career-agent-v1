# Deferred Scope

These ideas are intentionally absent from runtime code and navigation. They require separate user evidence and should not be presented as completed features.

- Order tracking and delivery-carrier integrations.
- WhatsApp messaging and automatic comment replies.
- Google Drive catalog import.
- Long-term customer memory or sensitive profiles.
- Campaign analytics and optimization agent.
- Independent inventory, recommendation, or supervisor agents.
- Dynamic LangGraph orchestration.
- Reels, Stories, carousels, and advanced scheduling.
- Multi-store tenancy, subscription billing, and payment collection.
- Automatic publishing without human approval.

## Re-entry rule

A deferred feature needs a named user problem, owner, success metric, security/privacy analysis, data contract, failure behavior, and automated acceptance test before implementation begins.
