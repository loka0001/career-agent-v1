التشغيل في خمس دقائق

  1. افتح رابط المنتج: http://127.0.0.1:5173 (local demo)
  2. سجل الدخول بالحساب التجريبي:
    merchant@example.com
    one-time password printed by scripts.bootstrap_env
  3. افتح مركز القيادة وتأكد أن مؤشرات المبيعات والفرص والطلبات ظاهرة.
  4. افتح المنتجات وتأكد أن الكتالوج يحتوي على 24 منتجًا تجريبيًا.
  5. افتح المبيعات واكتب: «عايز سماعة للمكالمات والمذاكرة أقل من 1500 جنيه».
  6. تأكد أن الرد يعرض منتجات حقيقية من الكتالوج مع السعر والمخزون وأسباب الترشيح.
بيانات الدخول السابقة للعرض التجريبي فقط. أنشئ مؤسسة ومستخدمًا جديدًا لكل عميل، ولا تسلم حسابًا مشتركًا في التشغيل الفعلي.

دورة الاستخدام اليومية

1. مركز القيادة

ابدأ منه لمراجعة الفرص ذات القيمة، الطلبات التي تحتاج متابعة، المحتوى المنتظر موافقة، ونتائج الأتمتة.

2. إدارة المنتجات

  1. أضف المنتج بالاسم والتصنيف والسعر والمخزون والمزايا.
  2. ارفع صورة PNG أو JPEG أو WebP.
  3. راجع الحقائق المستخرجة ثم فعّل المنتج.
  4. اختبر البحث عنه بعبارة عربية مختلفة عن اسمه الحرفي.

3. صندوق الرسائل والمبيعات

تظهر محادثات الموقع وWhatsApp وMessenger وInstagram والتعليقات في مكان واحد. افتح المحادثة، راجع نية العميل، ثم اعتمد الرد أو أنشئ طلبًا.

4. الطلبات والعملاء

راجع عناصر الطلب والسعر والحالة. الانتقال إلى pending يحجز المخزون، والإلغاء يعيده. ملف العميل يعرض السجل والاهتمامات والرضا والاحتمال الشرائي ومخاطر التوقف.

5. محرك فرص الإيراد

يعرض فرصًا قابلة للتنفيذ مثل نية شراء لم تُغلق، إعادة شراء، cross-sell، بديل لنفاد المخزون، أو فجوة محتوى. كل فرصة لها سبب وقيمة متوقعة وإجراء وموافقة وتتبع نتيجة.

6. الأتمتة

أنشئ Trigger وشروطًا وتأخيرًا وإجراءً. اختبر الأتمتة في الوضع التجريبي، راجع سجل التشغيل والمحاولات، ثم فعّلها على قناة حية بعد موافقة العميل.

ربط القنوات والموقع

Facebook وInstagram

  1. يملك العميل Meta Business وحساب Facebook Page وحساب Instagram Professional مرتبطًا بالصفحة.
  2. أنشئ Meta App وأضف Facebook Login وWebhooks والمنتجات المطلوبة.
  3. ضع App ID وApp Secret وOAuth callback في متغيرات Vercel السرية.
  4. نفذ الربط من صفحة التكاملات واختر الصفحة وحساب Instagram.
  5. شغّل فحص الاتصال للقراءة فقط قبل السماح بالنشر أو الرد.
  6. نفذ منشور اختبار واحد بعد الموافقة وراجع Provider ID وسجل التدقيق.

WhatsApp Business

  1. أدخل Phone Number ID وWhatsApp Business Account ID وAccess Token وApp Secret وVerify Token.
  2. سجل رابط Webhook الذي تعرضه صفحة التكاملات لدى Meta.
  3. اختبر رسالة واردة، وحالات sent وdelivered وread وfailed.
  4. اختبر الرد داخل نافذة 24 ساعة، ثم Template معتمد خارجها.
  5. اختبر opt-out وتأكد أن الأتمتة لا ترسل بعد سحب الموافقة.

موقع العميل

  1. أنشئ API key مخصصًا للموقع بأقل صلاحيات لازمة.
  2. انسخ كود Widget من إعدادات الموقع وضعه قبل إغلاق وسم </body>.
  3. اضبط الدومين المسموح، ولا تستخدم * في الإنتاج.
  4. اختبر فتح المحادثة والمنتجات والحدث التحليلي والطلب من نافذة خاصة.

إنشاء محتوى السوشيال

  1. افتح استوديو المحتوى واختر المنتج والمنصة والهدف ونبرة العلامة.
  2. أنشئ الفكرة والكابشن والوسوم والدعوة لاتخاذ إجراء.
  3. راجع السعر والمخزون والمواصفات؛ النظام يمنع الادعاءات غير الموجودة في الكتالوج.
  4. أعد توليد القسم المطلوب فقط بدل إعادة الحملة بالكامل.
  5. اعتمد المحتوى وحدد موعده في التقويم.
  6. في الوضع الحي، راجع الصورة ونسبة أبعادها وصلاحية Token ثم انشر.
  7. بعد النشر راقب التفاعل والمحادثات والطلبات المنسوبة للحملة.

خطة الفحص الكاملة

أ. فحص البنية

GET /health/live
GET /health/ready
GET /docs

النتيجة المطلوبة: HTTP 200، وداخل readiness تكون database وsearch وjob_queue بقيمة true.

ب. فحص رحلة البيع

  1. سجل مؤسسة جديدة ومتجرًا جديدًا.
  2. أضف منتجين وفعّلهما.
  3. اسأل بالعربية عن منتج تحت ميزانية محددة.
  4. حوّل الترشيح إلى طلب Draft ثم Pending.
  5. تأكد أن المخزون انخفض مرة واحدة فقط.
  6. ألغ الطلب وتأكد أن المخزون عاد.
  7. راجع العميل والفرصة وسجل التدقيق والتحليلات.

ج. فحص المحتوى

  1. أنشئ Post وStory وحملة من عدة منشورات.
  2. تأكد أن الكابشن والوسوم موجودة وأن الحقائق مطابقة للمنتج.
  3. اختبر الرفض والتعديل والموافقة والجدولة والنشر التجريبي.

د. فحص الأمان والعزل

  1. تأكد أن صفحات الإدارة لا تعمل بدون جلسة.
  2. اختبر رفض POST بدون CSRF بعد تسجيل الدخول.
  3. أنشئ متجرين وتأكد أن مستخدم متجر لا يقرأ منتجات أو عملاء المتجر الآخر.
  4. كرر تسجيل الدخول الخاطئ وتأكد من ظهور HTTP 429.
  5. تأكد أن الاستجابات لا تعرض Tokens أو Secrets.

هـ. فحص الواجهة

  1. اختبر عرض 390px والهاتف الأفقي وسطح المكتب.
  2. اختبر العربية RTL والإنجليزية LTR والوضعين الفاتح والداكن.
  3. تأكد من عدم وجود تمرير أفقي أو نص مقطوع أو عناصر متداخلة.
  4. فعّل Reduce Motion من النظام وتأكد أن الوظائف تظل واضحة.
  5. افتح Developer Tools وتأكد من عدم وجود أخطاء Console أو طلبات 4xx/5xx غير متوقعة.
